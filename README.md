# PVZRH_RogueShooting-UltimateSunChomper
植物大战僵尸融合版-终焉级圣樱战神的诸神进化版本，使用恒小暝的诸神进化库制作

这是圣樱战神的诸神进化模式，安装它你将可以在诸神进化模式游玩终焉级圣樱战神！

## 基础强化

圣樱进入诸神进化模式后获得：

- 支持圣樱的诸神进化路线
- 通用词条
- 保留圣樱本体原有的攻击、吞食和坚果机制

## 专属词条

### 质变：终焉意志·圣樱

效果：

- 索敌范围增加 2 格
- 攻击力大幅提高

### 质变：大胃袋

效果：

- 吞食消化时间降低为 5 秒
- 回复效果提高为原来的 3 倍

这两个词条由附属 DLL 通过 `ShootingMODGeneralLib` 注册，只属于诸神进化模式，不影响普通模式下本体的同名词条

## 超进化：星辉

获得星辉后，圣樱会获得额外强化

- 吞食消化时间降低为 5 秒
- 每次成功吞食时，在草坪每一行的最左侧生成一颗巨型圣樱坚果
- 坚果会沿对应行向右滚动并攻击僵尸
- 点击星辉圣樱时，同样会在每一行最左侧生成一颗巨型圣樱坚果

## 点击效果

圣樱本体原有的点击效果仍然保留：

- 点击消耗阳光
- 回复圣神生命
- 生成本体原有的巨型圣樱坚果

在诸神进化模式且获得星辉后，额外追加每行坚果滚动效果

## 兼容性

- 作为独立附属 DLL 工作
- 兼容现成的圣樱本体 DLL
- 不需要修改本体源码或替换本体 DLL
- 普通模式下的圣樱能力和本体词条不受影响
- 需要 `ShootingMODGeneralLib` 和圣樱本体插件正常加载
